# Hotel Logo Assets

- Keep the highest-quality source available. Prefer SVG; keep PNG fallback when intentionally maintained.
- Filenames use lowercase kebab-case.
- SVG and PNG fallback pairs may coexist.
- Web pages normalize visual logo size with CSS; source dimensions are not required to be 40px.
- Royal Park white wordmark is displayed on light cards with CSS inversion; the source SVG is preserved.
